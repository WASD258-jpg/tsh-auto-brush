# TSH自动刷课

油猴脚本：自动完成清华社英语在线（`www.tsinghuaelt.com`）的教材学习——自动答题、翻页、跨单元推进、查成绩、刷学习时长，可选接入 OpenAI 兼容 AI 接口直接出答案。

- 作者：WASD258-jpg
- 文件：`tsh-auto-brush.user.js`
- 版本：v1.1.2
- 协议：[GPL-3.0](LICENSE)
- 适用：清华社英语在线 教材学习（自由模式）

---

## 功能

| 功能 | 说明 |
| --- | --- |
| 全自动刷课 | 进入练习页后点"开始刷课"，自动答题 + 右箭头翻页，跨任务/跨单元自动前进，刷完整门课自动停止 |
| 自动答题 | 单选 / 多选 / 判断 / 下拉 / 填空 / 跟读 / 口语 / 角色扮演 / 拖拽 / 视频 |
| AI 优先 | 配置 OpenAI 兼容接口后 AI 出答案直接填；失败自动回退试错法（提交一次读答案修正，保证全对） |
| 查成绩 | 一键查询综合成绩、排名、各维度得分（完成率 / 学习时长 / 学习得分等） |
| 刷学习时长 | 挂机自动上报学习时长（综合成绩维度之一） |
| 反作弊规避 | 自动控制操作频率、识别限流并冷却自愈（约 90 秒），降低触发"系统繁忙"概率 |
| 失效自动上报 | 站点改版导致脚本失效时，经用户同意自动向 GitHub 发 issue（24 小时去重） |

## 安装

1. 浏览器安装 Tampermonkey（油猴）
2. 打开 Tampermonkey 管理面板，新建脚本
3. 粘贴 `tsh-auto-brush.user.js` 全部内容，保存
4. 打开 `www.tsinghuaelt.com` 并登录

## 使用

页面右下角为控制面板：

| 按钮 | 作用 |
| --- | --- |
| 开始刷课 | 全自动：进入上次学习任务，答题、翻页、跨任务/单元自动推进，全部完成自动停止 |
| 做一题 | 只执行一轮（当前页答题或翻页） |
| 查成绩 | 显示综合成绩、排名、各维度得分（点击后 3 秒冷却防限流） |
| 刷学习时长 | 挂机模式：每 10 秒上报学习时长（需在练习页） |

推荐流程：登录后进入任意练习页，点"开始刷课"挂机。建议保持页面在前台（后台标签页可能暂停计时）。偶发限流会自动冷却恢复，无需人工干预。

首次使用会依次弹出知情同意书与使用引导，请阅读后操作。

## AI 配置（可选）

面板"设置"打开设置面板：

1. 勾选"启用 AI 答题"
2. API Base URL：OpenAI 兼容接口地址，如 DeepSeek `https://api.deepseek.com/v1`
3. API Key：你的密钥
4. 模型名：如 `deepseek-chat`
5. 保存（存本地 localStorage，只填一次）

启用后 AI 先作答，提交后仍会读答案修正，保证全对。AI 不可用或超时自动回退试错法，答题不中断。

## 成绩机制

综合成绩 = 各维度按老师配置占比加权：

```
学习时长分 = min(实际时长 / 满分目标, 1) x 学习时长占比
完成率分   = min(实际完成率 / 满分目标, 1) x 完成率占比
学习得分   = 学习得分 x 学习得分占比
作业 / 测试 / 期末 = 各自占比（如有）
```

学习时长满分目标通常只有几小时，挂机刷课即可拿满；完成率刷满对应比例即满分；学习得分 = 答题正确率，脚本保证全对。

## 失效自动上报（开源协作，可选）

脚本内置有效性检测：在课程/练习页检测核心 DOM 结构，若连续多轮全缺失（站点改版）则判定脚本失效，经你同意后自动向 GitHub 仓库发 issue，便于开发者及时修复。

- 首次启用会弹**知情同意书**，默认不允许；同意后才显示并可用上报设置（仍默认关闭）
- 设置面板"失效上报"：启用开关 + GitHub 用户名/仓库名 + Token + 发测试 issue 验证
- Token 创建：GitHub Settings > Developer settings > Personal access tokens > Fine-grained tokens，仓库权限勾选 Issues: Read and write
- 隐私：issue 内容仅含脚本版本、已打码的页面路径（课程/用户 ID 已替换为占位符）、检测结果、时间；24 小时内同版本只发一次

**安全提示**：Token 与 AI 的 API Key 存本地 localStorage（明文），请使用权限最小化的令牌（GitHub fine-grained token 仅授权该仓库、仅 Issues: write 权限）。泄露后立即到 GitHub 撤销重建。启用 AI 后题目文本会发送到你配置的 API 服务商，失效上报只发 GitHub，内容不含题库。

## 已知限制

- 单选 / 多选 / 判断 / 下拉 / 填空 / 跟读已实测；拖拽 / 口语 / 角色扮演 / 视频基于站点结构实现，如遇异常请提 issue
- 作业/考试模块有全屏监控、切屏自动提交、人脸抓拍等强反作弊，脚本不触碰，也请勿手动用于作业测试
- 脚本依赖当前站点 DOM 结构，站点改版可能导致失效（失效上报会自动通知）
